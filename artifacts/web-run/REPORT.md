# Задание 27: приложение с локальной LLM

Реализован веб-чат на Go с Ollama и qwen3:8b. Пользователь вводит сообщение в браузере, приложение передаёт его вместе с историей в локальный /api/chat и показывает ответ по мере генерации. Облачные модели не используются.

## Docker

Запуск: `docker compose up -d --build`. Интерфейс: http://127.0.0.1:8081.

- model-init подготавливает веса в постоянном томе и завершает работу.
- ollama выполняет модель, OLLAMA_NO_CLOUD=1.
- app обслуживает UI и API; gateway (Nginx) передаёт запросы браузера без буферизации.
- app и ollama подключены только к сети runtime с internal=true; Ollama API не публикуется на хост.
- Фактическая попытка TCP-соединения из контейнера модели к 1.1.1.1:443 завершилась с Network is unreachable. [Сведения об окружении и проверке сети](environment.json).

Проверено на Docker Desktop, Apple M1 Pro; у Docker примерно 8 GiB RAM. Модель внутри контейнера выполняется на CPU. GPU-конфигурация для Linux/NVIDIA добавлена, её синтаксис проверен; запуск с GPU на текущем Mac не выполнялся.

## Реальные запросы через приложение

Команда: `python3 scripts/verify-web.py`. Сохранены исходные запросы, все потоковые события и ответы. Режим без рассуждений используется в первых четырёх сценариях; пятый включает think=true. Температура 0,2, контекст 4096, максимум 2048 выходных токенов, тайм-аут 5 минут.

Completed at: 2026-10-11T17:23:05.808334+00:00 (UTC).

| Scenario | think | Time (s) | Output tokens | Streaming deltas | Result |
|---|---|---:|---:|---:|---|
| 01-fact | false | 23.78 | 4 | 3 | passed |
| 02-math | false | 37.84 | 146 | 145 | passed |
| 03-history | false | 50.75 | 146 | 145 | passed |
| 04-code | false | 27.22 | 81 | 80 | passed |
| 05-think | true | 45.63 | 161 | 1 | passed |

Все пять проверок итогового прогона прошли. Итоговые ответы на расчёт и уточнение — 3060 и 2880 рублей. Функция Unique с map сохраняет порядок; сгенерированный код без правок прошёл шесть случаев: пример, nil, пустой ввод, одинаковые элементы, отрицательные числа/ноль и уникальные элементы.

При think=false отдельные рассуждения отсутствовали; объяснение вычислений было явно запрошено пользователем. При think=true рассуждения приходили отдельными событиями thinking, а итоговый ответ — событиями delta. Ответы завершились событием done, не достигли лимита выходных токенов.

### Ограничение качества модели

Первый прогон с просьбой вернуть только итоговую сумму дал неправильные 1710 и 1440 рублей. [Эти исходные ответы сохранены](initial-short-answers.json). Затем проверили запрос с показом вычислений, совпадающий с примером в интерфейсе: модель вернула правильные 3060 и 2880. Приложение не исправляло и не подменяло текст ответов. Проверка успешной интеграции не гарантирует правильности любых ответов LLM.

## Проверки интерфейса

Через браузер проверены отправка вопроса, поступление ответа, уточнение с историей, восстановление истории после перезагрузки, новый диалог, переключение режима рассуждений, остановка генерации, ошибка при отключённой Ollama и восстановление после её запуска. Остановленные и ошибочные обмены не включаются в следующие запросы. [Фактические результаты UI-проверок](ui-checks.json).

Дополнительно через UI сравнили 2 + 2: think=true — 48,9 с / 195 токенов, think=false — 3,7 с / 2 токена. В обоих случаях ответ 4. Отдельный блок рассуждений раскрывается и сворачивается; при false он отсутствует.

## Проверки кода

Пройдены go test -race ./..., go vet ./..., проверка синтаксиса JavaScript, Python и обеих Compose-конфигураций. Docker-сборка также запускает go test и go vet. Тестами проверены поток до завершения генерации, отдельное поле thinking, сохранение истории, ограничение размера контекста, ошибки API/потока, тайм-аут, занятость модели и передача отмены из браузерного запроса до upstream HTTP-запроса Ollama.

Для повторной проверки после запуска Docker:

```sh
python3 scripts/verify-web.py --output artifacts/another-web-run
```
