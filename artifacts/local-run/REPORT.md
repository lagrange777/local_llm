Параметры: `think=true`, `temperature=0.6`, `num_ctx=4096`, `num_predict=3072`, тайм-аут 3 минуты. Время измерено клиентом; скорость вычислена по `eval_count / eval_duration` и включает токены рассуждения. Это демонстрационный прогон, а не нагрузочный тест.

## CLI

```sh
ollama run qwen3:4b --think=true --hidethinking "Назови столицу Франции. Ответь одним предложением на русском языке."
```

Фактический ответ: «Столица Франции — Париж».

Код завершения 0; время клиента 42.95 с. CLI выполнялся одновременно с HTTP-прогоном и мог ждать очередь модели.

## Проверка сгенерированного кода

Функция использует map и один проход: ожидаемая средняя сложность O(n), дополнительная память O(n). Проверены пример [3, 1, 3, 2, 1], nil, пустой срез, одинаковые числа, отрицательные числа и ноль, последовательность без дубликатов.

Код извлечён без правок. Модель вернула текст функции вместо запрошенного блока go; это ограничение качества форматирования.

## Предварительный прогон

При `think=false` модель добавляла рассуждения в ответ; второй запрос достиг лимита 768 токенов. Переключатель /no_think и отдельный шаблон также не обеспечили стабильного короткого ответа. Итоговая проверка использует штатный режим `think=true` и лимит 3072 токена. Диагностический вариант модели удалён.
