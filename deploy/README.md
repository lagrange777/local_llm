# Развёртывание

Каталог для Dockerfile, Compose и конфигурации выбранного облака.

После реализации API конфигурация должна описывать два компонента: HTTP-сервис на Go и Ollama. Сервис обращается к Ollama по настраиваемому адресу; веса модели сохраняются в отдельном томе.

Перед выбором облачной машины измерим потребление памяти и скорость модели. Конкретное облако и CPU/GPU-конфигурация пока не выбраны.
