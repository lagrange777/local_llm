# Local LLM Service

Отдельный проект HTTP-сервиса для локальной языковой модели с последующим развёртыванием в облаке.

Стек: Go и Ollama. Начальная модель для проверки — `qwen3:4b`.

## Текущее состояние

Создан каркас проекта и инициализирован Git. HTTP-сервис, установка модели и прогоны запросов будут реализованы следующим шагом.

## Структура

```text
cmd/server/       точка входа HTTP-сервиса
internal/ollama/  клиент API Ollama
deploy/          конфигурация развёртывания
artifacts/        результаты проверок модели
```

## Порядок реализации

1. Установить и запустить Ollama локально, скачать модель.
2. Проверить CLI и HTTP API на трёх запросах разной сложности.
3. Сохранить реальные ответы, версии, время выполнения и метрики.
4. Реализовать HTTP-сервис на Go: проверку доступности модели и генерацию ответа.
5. Добавить Docker-сборку и конфигурацию для выбранного облачного окружения.

## Архитектура

Клиент → HTTP-сервис на Go → Ollama → локальные веса модели.

Адрес Ollama задаётся конфигурацией: при разработке это локальный процесс, при развёртывании — отдельный сервис. Веса модели и данные хранятся отдельно от исходников.

`.env.example` содержит планируемые настройки. Загрузка этих настроек появится вместе с реализацией сервиса.
