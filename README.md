# Local LLM Service

Локальная языковая модель Ollama + Qwen3 и Go-клиент для воспроизводимой проверки. Проект создаётся отдельно от RAG-чата; следующий этап — HTTP-сервис и развёртывание в облаке.

[Отчёт о выполнении задания](artifacts/local-run/REPORT.md)

## Запуск на macOS

Нужны Homebrew, Python 3 и Go 1.25 или новее.

```sh
brew install ollama
python3 scripts/start-ollama.py
ollama pull qwen3:4b
```

Скрипт запускает фоновый процесс на `127.0.0.1:11434` с `OLLAMA_NO_CLOUD=1`. Веса хранятся в `data/models/`, журнал и PID — в `tmp/`; эти каталоги исключены из Git. Если порт уже занят Ollama, скрипт сообщает об этом и не меняет настройки существующего процесса. После перезагрузки компьютера скрипт запускают снова.

Установка пакета и загрузка весов используют интернет. Генерация выполняется на Mac через локальный HTTP API.

## Запрос через CLI

```sh
ollama run qwen3:4b --think=true "Назови столицу Франции. Ответь одним предложением."
```

## Запрос через HTTP

```sh
curl --fail-with-body http://127.0.0.1:11434/api/generate \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen3:4b","prompt":"Сколько будет 2 + 2?","stream":false,"think":true,"options":{"num_ctx":4096,"num_predict":3072}}'
```

## Три запроса разной сложности

```sh
go run ./cmd/verify
```

Программа последовательно задаёт три вопроса: простой факт, расчёт скидки и генерация Go-функции. Для каждого сохраняются исходный запрос, ожидание, ответ, время и скорость генерации в `artifacts/local-run/`. Ожидания служат критериями ручной проверки; программа проверяет успешность API и полноту ответа, но не оценивает смысл текста автоматически.

Qwen3 запускается в режиме рассуждения. При предварительной проверке `think=false` и `/no_think` не обеспечили короткий ответ в установленной связке; расчёт достигал лимита 768 токенов. Итоговый прогон использует штатный режим и увеличенный лимит.

Фиксированные параметры: `think=true`, `temperature=0.6`, контекст 4096 токенов, максимум 3072 выходных токенов, тайм-аут 3 минуты на запрос. Повторный запуск обновляет файлы результатов. Выберите другой каталог, чтобы сохранить отдельный прогон:

```sh
go run ./cmd/verify -output artifacts/another-run
```

Адрес и модель задаются флагами `-url`, `-model` или переменными `OLLAMA_BASE_URL`, `OLLAMA_MODEL`. Настройки `.env.example` нужно экспортировать в оболочку: файл не загружается автоматически.

```sh
go test ./...

ollama list

curl --fail http://127.0.0.1:11434/api/version
```

## Структура

```text
cmd/verify/       прогон контрольных запросов
internal/ollama/  HTTP-клиент Ollama и его тесты
scripts/         запуск локального процесса
deploy/          место для будущего облачного развёртывания
artifacts/       реальные результаты и отчёт
data/models/     веса модели (исключены из Git)
tmp/             журнал и PID процесса (исключены из Git)
```

## Следующий этап

HTTP-сервис на Go будет обращаться к Ollama по настраиваемому адресу. Для облака добавим сборку сервиса и отдельный контейнер Ollama с томом для весов. Конкретный провайдер и CPU/GPU-конфигурация ещё не выбраны.

Официальные источники: [установка на macOS](https://docs.ollama.com/macos), [Qwen3 4B](https://ollama.com/library/qwen3:4b), [HTTP API генерации](https://docs.ollama.com/api/generate), [локальный режим и GPU](https://docs.ollama.com/faq).
